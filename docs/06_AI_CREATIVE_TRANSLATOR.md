# 06 — AI as a Creative Translator

## Product question

Can AI help a creator translate artistic intent into an editable lighting starting point **without taking authorship away from the creator**?

This is an optional product direction only after the underlying translation problem is validated.

---

## 1. What not to build

Avoid:

> sad song = blue lights

Avoid one-click “perfect show generation.”

Avoid pretending there is one correct visual meaning for a song.

---

## 2. Better model

The creator remains the authority.

AI helps translate:

**artist intent  
→ musical structure / semantics  
→ perceptual / dramatic language  
→ visual grammar  
→ editable EMU / ELM controls**

Example:

> “The final chorus should feel much wider than the first, but not more aggressive.”

The system could suggest:

- relevant section
- spatial expansion
- intensity range
- movement logic
- transition pace
- sync / drift / restraint
- alternative visual strategies

The artist can reject, edit, combine or lock suggestions.

---

## 3. Research foundation before automation

The valuable dataset is not merely:

**audio feature → lighting parameter**

It is:

**musical element  
→ artist-defined role  
→ artistic intent  
→ desired sound/light relationship  
→ visual primitive  
→ actual EMU decision  
→ artist evaluation**

Kick is not universally a flash.  
Bass is not universally dark.  
Vocals are not universally a spotlight.

First learn the translation grammar with musicians.

Only then automate parts of it.

---

## 4. MVP sequence

### MVP A — Intent-to-brief
Convert creator language into a structured visual brief.

### MVP B — Section-aware variation
Suggest controlled differences between repeated song sections.

### MVP C — Relationship presets
Test creator-readable relationships:
- synchronized
- restrained
- drifting
- counterpoint
- generative

### MVP D — Artist-defined visual grammar
Let creators build a reusable visual vocabulary across songs.

---

## 5. Product role by complexity level

### Quick / Template
AI can be relatively proactive:
- suggest a starting style
- detect sections
- propose a first result

### Creator
AI acts like a copilot:
- explain suggestions
- propose alternatives
- respond to natural-language intent

### Advanced
AI can be optional or disabled:
- never hide manual controls
- never rewrite project logic silently

---

## 6. Guardrails

- creator can override everything
- suggestions remain editable
- uncertainty is visible where useful
- manual authoring remains first-class
- accepted output can be recalled deterministically
- fixture / project constraints are respected
- creator data / Artist Lab data requires appropriate consent and governance

North-star:

> **AI assists expression; it does not automate taste.**

# 中文版

## 06 — AI 作为 Creative Translator

### 产品问题

AI 能不能帮助创作者把艺术意图翻译成一个可编辑的灯光起点，**同时不夺走创作者的作者权**？

只有底层 translation problem 被验证后，这个方向才值得做。

---

## 1. 不应该做什么

不要：

> 悲伤歌曲 = 蓝灯

不要“一键完美灯光秀”。

不要假装一首歌只有一个正确视觉含义。

---

## 2. 更好的模型

Creator 保留最终 authority。

AI 帮助翻译：

**artist intent  
→ musical structure / semantics  
→ perceptual / dramatic language  
→ visual grammar  
→ editable EMU / ELM controls**

例如：

> “最后一个副歌应该更宽，但不要更凶。”

系统可以建议：

- section
- spatial expansion
- intensity range
- movement logic
- transition pace
- sync / drift / restraint
- alternative visual strategy

音乐人可以拒绝、修改、组合或锁定。

---

## 3. 自动化之前先研究

真正有价值的数据不是：

**audio feature → lighting parameter**

而是：

**musical element  
→ artist-defined role  
→ artistic intent  
→ desired sound/light relationship  
→ visual primitive  
→ actual EMU decision  
→ artist evaluation**

kick 不天然等于闪光。  
bass 不天然等于深色。  
vocal 不天然等于 spotlight。

先和音乐人理解 translation grammar，再自动化。

---

## 4. MVP 顺序

### MVP A — Intent-to-brief
把 creator language 变成 structured visual brief。

### MVP B — Section-aware variation
给重复歌曲段落建议可控变化。

### MVP C — Relationship presets
测试 creator 可理解关系：
- synchronized
- restrained
- drifting
- counterpoint
- generative

### MVP D — Artist-defined visual grammar
让 creator 建立跨歌曲复用视觉语言。

---

## 5. 不同复杂度里的 AI 角色

### Quick / Template
AI 可以更主动：
- 推荐 starting style
- 检测 section
- 给 first result

### Creator
AI 更像 copilot：
- 解释建议
- 提供 alternatives
- 理解 natural-language intent

### Advanced
AI 可以 optional / disabled：
- 不隐藏 manual control
- 不静默改 project logic

---

## 6. Guardrails

- creator 可以 override 一切
- suggestion 可编辑
- 必要时展示 uncertainty
- manual authoring 始终一等
- 接受后的输出可 deterministic recall
- 尊重 fixture / project constraint
- Artist Lab 数据使用需要 consent 与 governance

North-star：

> **AI 帮助表达，而不是自动化审美。**
