# 180-Day Roadmap & Metrics

## Goal

In six months, prove whether a Product Specialist-led creator discovery model can produce:

1. better product insight
2. stronger EMU creator activation
3. credible portfolio ideas for EMU / ELM
4. authentic content that supports growth

---

## Days 0–30 — Learn the system

### Product
- complete EMU workflows as a musician
- complete ELM workflows as a professional mapping user
- understand S-PLAY handoff / automation use cases
- map software / hardware ecosystem

### Organisation
- identify Product, Engineering, Support, Sales, Marketing owners
- document decision forums
- clarify Product Specialist decision rights
- understand current backlog / roadmap process

### User evidence
- review support tickets / FAQ themes
- review case studies
- interview internal customer-facing teams

### Deliverables
- product ecosystem map
- top 10 workflow friction list
- decision-rights map
- first research plan

---

## Days 31–60 — Creator discovery

### Research
- 10–15 musician / producer interviews
- 5–10 ELM professional interviews
- observe at least 5 real creation workflows

### Outputs
- creator journey
- professional journey
- recurring problem taxonomy
- 3 product hypotheses
- Artist Lab pilot spec

### Gate
Do not build AI features yet unless a validated problem requires them.

---

## Days 61–90 — Run the pilot

### Artist Lab
- recruit first 3–5 creators
- produce 2–3 pilot episodes
- document intent cards
- identify at least one repeated unmet need

### Product
- prototype one workflow improvement
- test with multiple creators
- define success / kill criteria

### Community
- launch comments-to-hypotheses process
- establish transparent backlog language

---

## Months 4–6 — Prove repeatability

### Product
- repeat experiment across creators
- decide: kill / iterate / ship
- test whether any capability has ELM relevance

### Program
- publish regular Artist Lab cadence
- formalise creator partner selection
- define host / educator model

### Internal
- quarterly product insight report
- proposal for shared creative primitives only if evidence supports it

---

## KPI dashboard

### North-star candidates
Choose one after baseline research:
- percentage of new creators reaching first expressive show
- median time to first expressive show
- repeat creation within 30 days

### Discovery
- validated problems / quarter
- hypotheses killed before engineering investment
- time from insight to user test
- percentage of experiments tested with 3+ creators

### Product
- adoption
- repeat usage
- workflow completion
- user confidence
- support-load reduction

### Content
- qualified downloads
- episode completion
- creator applications
- percentage of comments yielding useful hypotheses

### Portfolio
- cross-product primitives identified
- professional validation of graduated capabilities
- duplicated engineering avoided

---

## Decision framework for feature investment

Score each opportunity on:

- user pain
- frequency
- strategic fit
- differentiation
- creator value
- professional value
- implementation cost
- support cost
- cross-product leverage
- evidence quality

Do not prioritise solely by:
- loud customer
- famous artist request
- social engagement
- novelty / AI appeal
